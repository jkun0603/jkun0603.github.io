设置 GitHub 令牌

需要配置一个 GitHub 访问令牌才能发布文章。

  1. 打开 github.com/settings/tokens
  2. 点击 Generate new token → Fine-grained token
  3. Repository access: 选 Only select repositories → 选 jkun0603/jkun0603.github.io
  4. Permissions: 把 Contents 设为 Read and write
  5. 生成后复制令牌粘贴到下面

✏️ 写文章

用于 URL：/blog/view.html?slug=my-post-title
