Three.js 入门笔记

WebGL 与 Three.js 的基础概念，以及如何创建第一个 3D 场景。

什么是 Three.js？

Three.js 是一个基于 WebGL 的 JavaScript 3D 库，封装了底层图形 API，让开发者能用更简洁的代码创建 3D 场景。

核心概念

  • Scene（场景） — 所有物体的容器
  • Camera（相机） — 决定观察角度，常用 PerspectiveCamera 和 OrthographicCamera
  • Renderer（渲染器） — 将场景绘制到画布上
  • Mesh（网格） — 几何体 + 材质的组合
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, W/H, 0.1, 1000);
const renderer = new THREE.WebGLRenderer({ alpha: true });

const geo = new THREE.BoxGeometry(1, 1, 1);
const mat = new THREE.MeshBasicMaterial({ color: 0xff6b6b });
const mesh = new THREE.Mesh(geo, mat);
scene.add(mesh);

function animate() {
  mesh.rotation.x += 0.01;
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}
