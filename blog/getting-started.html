我的第一篇博客文章

欢迎来到我的个人网站！这是第一篇文章，想分享一下搭建这个站的初衷和过程。

为什么搭建个人站？

一直以来都想拥有一个属于自己的网络空间。在这个信息爆炸的时代， 社交媒体虽然方便，但总觉得缺少一点「属于自己」的感觉。 个人网站就像数字世界中的家——你可以自由地设计它、装饰它， 让它完全按照你的想象呈现。

这个网站承载着几个目标：

  • 作品集 — 展示我的项目与成果
  • 博客 — 记录学习笔记与思考
  • 个人品牌 — 塑造专业的线上形象

技术选型

这次选择了最纯粹的方式：原生 HTML + CSS + JavaScript，没有使用任何框架。 原因很简单：

  • 加载速度快，不依赖任何构建工具
  • 对每个像素都有完全的控制力
  • 适合作为长期维护的个人站点

通过 CSS 变量实现了深色/浅色主题切换，使用 Intersection Observer 实现了滚动加载动画，整个站点都是响应式设计。 

// 主题切换实现
function toggleTheme() {
  const current = document.documentElement
    .getAttribute('data-theme');
  const next = current === 'dark' ? 'light' : 'dark';
  document.documentElement
    .setAttribute('data-theme', next);
  localStorage.setItem('theme', next);
}

接下来的计划

这个网站会持续更新。我计划定期发布技术博客文章， 不断优化网站的设计与性能。如果你有任何建议或想法， 欢迎通过联系页面与我交流。
