响应式设计实战

从移动优先到桌面端，响应式设计是现代 Web 开发的必备技能。

移动优先策略

先写移动端样式，再用 min-width 媒体查询逐步增强。这样可以保证基础体验在所有设备上一致。

/* 基础样式：移动端 */
.grid { display: flex; flex-direction: column; gap: 16px; }

/* 平板 */
@media (min-width: 768px) {
  .grid { display: grid; grid-template-columns: 1fr 1fr; }
}

/* 桌面 */
@media (min-width: 1024px) {
  .grid { grid-template-columns: 1fr 1fr 1fr; }
}

相对单位

使用 rem、em、vh、vw 等相对单位代替 px，让布局自适应屏幕尺寸。

图片响应式

使用 max-width: 100% 和 picture 元素为不同屏幕提供合适尺寸的图片。
