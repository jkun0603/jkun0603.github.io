理解现代 CSS 布局

Flexbox 和 Grid 是现代 CSS 布局的两大支柱。这篇文章梳理核心概念与实战技巧。

Flexbox：一维布局

Flexbox 适合在一行或一列中排列元素。核心概念：

  • 主轴与交叉轴 — flex-direction 控制主轴方向
  • justify-content — 主轴对齐方式
  • align-items — 交叉轴对齐方式
  • flex-wrap — 是否换行
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

Grid：二维布局

Grid 适合同时控制行和列的布局。核心概念：

  • grid-template-columns/rows — 定义行列结构
  • gap — 间距
  • grid-area — 元素跨行跨列
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
}

何时用哪个？

Flexbox 适合导航栏、卡片列表、居中等一维场景。Grid 适合整体页面布局、图片墙等二维场景。两者可以嵌套使用，并不互斥。
